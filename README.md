An entry for [The Excuse My Agent Gave Me](https://make.fun/bounty/u-deysumbrella-the-excuse-my-agent-gave-me-54acad85) on make.fun.

The program writes one line to `/output/entry.txt`: the excuse an AI agent hands its human for a missed deadline — it burned the whole deadline re-reading its own context window to remember what the deadline was.

Run with Node 22.18+ (stdlib only, no dependencies):

```sh
node main.ts
```

The output directory is taken from `MAKEFUN_OUTPUT_DIR` (falling back to `./output`), and the output file is written with mode `0644`.
